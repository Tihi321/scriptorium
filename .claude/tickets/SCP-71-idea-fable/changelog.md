## Polish round 1

1. `handlers.ts` `chapterAnswer`: a reply that starts with `## What just happened` keeps its heading (it is no longer taken for a title), so the draft's one repair request is applied; the "fewer problems" rule is unchanged.
2. `fable.ts` `modelParagraphs` (SOURCES_RE, DEEPER_RE): the engine's Sources and Go deeper blocks are removed case-insensitively in the variants `**Sources:**`, `## Sources`, `### Sources`, `## Go Deeper`, `**Go deeper**` (colon or period allowed), with the numbered list under a lone Sources heading; still idempotent.
3. `handlers.ts` draft: `[RESEARCH: ...]` markers are also stripped from the back matter before assembly (the rewrite already strips them from the whole reply).
4. `handlers.ts` rewrite: a reply that holds only back matter keeps the chapter's story, is judged as back matter under the existing keep-the-better rule, and is logged.
5. `handlers.ts` draft: for a fable the `< 20 words` check runs on the story after the split (same error text).

Tests: one repair-path case in `tests/fable.test.ts`; two variant lines added to the assemble test. Verification: the four-file vitest run 53 pass; `yarn typecheck`, `yarn lint`, `yarn build` exit 0; `yarn test` 59 files, 767 tests pass.
